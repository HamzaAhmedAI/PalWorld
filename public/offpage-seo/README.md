# 🚀 PalBreed.AI Off-Page SEO Strategy

This directory contains the complete off-page SEO strategy for PalBreed.AI.

## Files

| File | Purpose |
|------|---------|
| `01-reddit-strategy.md` | Reddit outreach plan with post templates |
| `02-quora-answers.md` | Quora answer templates for Palworld questions |
| `03-pinterest-strategy.md` | Pinterest pin designs and pinning schedule |
| `04-free-backlinks.md` | Free directory submissions and backlink opportunities |
| `05-master-calendar.md` | 90-day action plan and tracking |

## Quick Start

1. **Week 1:** Create accounts on Reddit, Quora, Pinterest
2. **Week 1-2:** Submit to directories from `04-free-backlinks.md`
3. **Week 2+:** Start Reddit engagement using `01-reddit-strategy.md`
4. **Week 2+:** Answer Quora questions using `02-quora-answers.md`
5. **Ongoing:** Create Pinterest pins using `03-pinterest-strategy.md`

## Goal

**45-60 quality backlinks in 3 months with $0 budget**

See `05-master-calendar.md` for the full 90-day timeline.
